This project supports multiple ways to trigger lamp control, each suited to different levels of precision and interaction. Below is a breakdown of the gestures/triggers used in each sensor/system.
1. IR+ultrasonic Sensor (Infrared Proximity)
ultrasonic - to switch on and off the lamp
IR sensor - 
Right - Left : change color
Left - Right : change color
Up - Down : Decrease Brightness
Down - Up: Increase Brightness
This is the test video 

3. APDS-9960 Gesture Sensor
Detects directional gestures with high precision.
up - turn on
down - turn off


4. PIR Sensor (Passive Infrared / Motion)
Detects motion in range (e.g., person walking by).
(Ideal for automatic lighting or occupancy-based control.)

5. Sound Sensor (Clap/Noise Detection)
Detects sound spikes such as a clap or snap.
